# Student Management System
A student manager in cpp inside the CLI.
It is a CRUD application using database.
Helps store data like subject marks, student name and age and calculates their percentage.
Prevents the storing of records using papers and files.

## How to run
In your terminal run these: 
1. use `git clone` this repo
2. and then just do `make run`
